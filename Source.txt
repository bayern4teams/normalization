============================================================
0. MOST IMPORTANT DESIGN PRINCIPLE
============================================================

NORMALIZATION MUST NOT MEAN:

"lowercase everything, remove punctuation, trim spaces"

That is insufficient and dangerous.

Normalization must be:

- field-aware
- semantic
- locale-aware
- deterministic where possible
- lossless by default
- reversible where practical
- versioned
- explainable
- auditable
- configurable
- reproducible
- scalable
- safe for entity resolution

The system must distinguish:

1. Raw value
2. Repaired value
3. Canonical semantic value
4. Search/comparison normalization
5. Optional lossy/transliterated value
6. Derived structured components

Never collapse these into one field.
