first docstring line matches `_TAX_ID_TITLE_TERMS = ("tax", "vat")` (word-prefix, case-insensitive; source stated in a comment).
Zero or several candidates -> (None, candidates). Names are dotted ("stdnum.pt.nif"). No network; stdnum is imported dynamically.
`_LEGACY_TAX_ID_MODULE` (US ein, GB vat, DE vat, FR siren) keeps today's modules (their titles give several/no candidates) with a
comment; it is the only 2-letter-literal table (allowed by the acceptance AST test).

structured verification="unverifiable", verification_reason, candidate_modules (several only), check_digit_valid None.
A non-validation exception from a stdnum module now yields unverifiable (reason "validator raised X"), not INVALID.
Old four countries: structured dict is byte-identical (4 keys, same order of values).
D8: CODE branch: canonicalization only; structured = cleaned, has_internal_separator, verification="not_applicable" (no check_digit_valid /
identifier_type keys); validation_status "UNKNOWN" (postcode precedent); normalization_status NORMALIZED; confidence 1.0.
