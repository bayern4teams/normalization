## Decisions
- Classification mirrors tests/defects/scorer.py. Truth clean: engine clean+right value=correct, clean+wrong/None value=wrong-confident, any non-clean=over-abstain (INVALID on a decidable input counts here, as there is no 5th class). Truth AMBIGUOUS: clean=wrong-confident (even a listed candidate), non-clean=correct-abstain. Truth INVALID: INVALID=correct, clean=wrong-confident, else over-abstain. `pairs` = (confidence, correct) for clean answers with a stated confidence only.
- default_engine: real `build_dispatcher` (lazy import, normapi imports normanalysis so top-level is a cycle), `comparison` else `display`, clean+validation UNKNOWN/AMBIGUOUS reported as AMBIGUOUS (same rule as scorer.real_engine).
- Injectors (6 families, kinds rotate with i so every kind appears once n >= kinds; one `random.Random(f"{seed}/{family}")` per family, string-seeded so PYTHONHASHSEED-independent; verified byte-identical for hash seeds 0 and 123):
  phone (libphonenumber example_number + its own round trip; national+region / international / region-removed = AMBIGUOUS), date (swap with both parts <=12 and different = AMBIGUOUS with two ISO candidates; day>12; day==month = decided; locale-resolved from the CLDR short date pattern; year-only stays year-only), numeric (lone d.ddd/d,ddd = AMBIGUOUS; both marks; repeated group mark; plain; locale via Babel format_decimal of a known value), email (domain lower-cased, local part case kept per RFC 5321), URL (scheme+host lower-cased, path kept; bare host = AMBIGUOUS), country (CLDR names in 7 locales, ISO 3166 via pycountry for the code set; a name two countries share is AMBIGUOUS, never picked).
  Seed words for email/URL are CLDR English territory names under the RFC 2606 `.example` TLD. No corpus literal in gold.py; the section 2.4 grep test passes.
- Ceilings (ponytail comments in file): six families only; BART/Raha only through the dirty/clean CSV loader (Raha's two-file dirty.csv/clean.csv must be merged first; CSV rows are PARSED with context {}); kappa/alpha nominal only; the 7 country locales are a coverage choice.

- Real engine on `generate_corpus(0, 30)` (180 cases): correct 142, correct-abstain 21, wrong-confident 11, over-abstain 6.
  - over-abstain 6: DATE same day and month (e.g. `08.08.2014`): engine says AMBIGUOUS, both readings give one date (`_is_ambiguous_numeric_date` ignores a==b).
  - wrong-confident 1: DATE `10/7/2026` with locale ee-GH: CLDR short pattern is M/d/y, engine's `_MDY_COUNTRIES` heuristic reads D/M and answers 2026-07-10 at 0.85.
  - wrong-confident 10: URL bare host (`somalia.example/Path`): engine assumes https at 0.8 (documented policy in url.py).
- `normcli gold score` on a generated file prints all four class names and names each wrong-confident/over-abstain case with expected vs got.

## Flags for the lead

- Tests are not wrong. They do forbid trailing whitespace on generated emails (leading padding is kept).
- normanalysis/pyproject.toml does not declare babel, phonenumbers, pycountry (all installed via normalizers/normcore in the workspace). I did not edit pyproject; add them there if normanalysis should stand alone.
