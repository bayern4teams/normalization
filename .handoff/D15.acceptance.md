## Names the checks assume (implementer: follow them, or tell the lead before changing)

| Name | Contract |
|---|---|
| `normapi.address_policy.classify(addr: str) -> bool` | True = allowed. Strict literal only: no resolving; decimal/octal/hex/short IPv4, whitespace, `%zone`, `/prefix`, brackets, names, empty -> False. `::ffff:a.b.c.d` is unwrapped first. |
| `normapi.address_policy.check_caller(peer: str \| None) -> bool` | True = caller allowed. Non-IP peers (`"testclient"`, `""`, `None`) -> False. Used by the ASGI middleware. |
| `normapi.address_policy.resolve_and_check(host: str) -> str` | Returns the checked IP literal to pass to libpq as `hostaddr`. Raises `AddressPolicyError` for: public/CGNAT/non-literal-form IP, hostname with ANY non-allowed address (R15), no or failed resolution, unix-socket path (`/...`, `@...`), multi-host or comma string, empty. Literals are never resolved. Resolves with `socket.getaddrinfo` (called as the module attribute so tests can patch it) and does not cache across calls. |
| `normapi.address_policy.AddressPolicyError(Exception)` | The refusal. |
| `normapi.clone_executor.build_postgres_dsn(host, port, username, password, database, hostaddr=None) -> str` | Built with `psycopg.conninfo.make_conninfo`; round-trips through `conninfo_to_dict`. |
| `normapi.app.create_app()` | No-argument call. A refused caller or Host answers HTTP 400 or 403; accepted requests answer anything below 500 (a 404 is fine). Path used: `/openapi.json`. |
| `compose.yaml` | Service `api` publishes via a `${...}` host address; every other service `127.0.0.1`; `NORM_SECRET_KEY` only as `${...}`. |

## Not covered here (attacker to verify, or unverified-live)

- `build_source_connector` / `build_destination_writer` call the check on every use, and the
  save-time check on `ConnectionCreateRequest.host` and `_resolve_connection` inline hosts: signatures
  unknown to the deriver. Attack by hand.
- `hostaddr` on real Postgres, the ClickHouse connection (pinning option not documented), Docker
  binding, a LAN caller, real multi-address DNS, Docker Engine version: need the live stack.
- The deployer setting that adds ranges (R14): its name is not in the report, so no test here.
- `NORM_API_HOST` default `0.0.0.0` and the Dockerfile `CMD`: left alone by these checks (inside a
  container it must listen on all container interfaces; compose does the host binding).
- Python minor version pin (fix 7): environment decision Q6 keeps 3.12; the table guards the rest.
- ADR-022 content and docs (J13) are not tested.
