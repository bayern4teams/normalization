## Ambiguity in the spec (decided; the worker brief must carry these)
- `report(pairs, *, cost_ratio, groups=None, bins=10) -> (dict, str)`: if the lead's signature differs, change only the `_report` adapter in the test. The CLI tests need no signature.
- `Reliability` has `.bins` (every bin listed, empty ones included, `len == bins`), `.ece`, `.overconfident_bins` (Bin objects or indexes, both accepted), `.groups` (label -> Reliability). Bins may be dataclasses or dicts. Bin edges: `[lo, hi)` except the last, which is closed.
- `ece_tolerance` is an upper confidence bound on the ECE of a calibrated predictor (not its mean), so a calibrated predictor stays inside it for the 12 fixed (n, seed) runs.
- Overconfidence is judged with a noise test the test does not fix; only the 1.0-vs-0.8 (n>=200) flagged and the exact-calibrated / under-confident / n=50 0.80-vs-0.78 not-flagged cases are pinned.
- Chow: emit iff `confidence >= t`; cost = ratio per wrong emitted value, 1 per abstention, 0 per right one. The test compares the COST of the returned threshold with the brute-force minimum, so any tie-break (and any t between observed confidences) is accepted. "Abstain on everything is optimal" is not tested (the threshold would be inf or None).
- AURC = mean selective risk over coverage levels (1/n sum of risk at top-k), not a trapezoid. Tied confidences are kept together so order cannot matter; the exact tied-group weighting is not pinned.
- `risk_coverage` points are `(coverage, risk)` tuples or objects with those attributes.
- Not tested: NaN cost ratio, confidences of `None` (D6 already drops them from `pairs`), Markdown layout, dispatch-time use (there must be none).
