## Choices and why
- Survey: `phonetics` (MIT, dmetaphone) ok. No permissive Python BMPM on PyPI (probed ~12 names; `abydos` GPL forbidden, not used). So: vendor Commons Codec rules + own port. `check_licenses.py`: only the pre-existing psycopg / psycopg-binary LGPL violations; phonetics reported as MIT, no new line.
- Beider-Morse language set is guessed by the rule file `gen_lang.txt` (the algorithm itself) and only selects rules; never reported.
- Deliberate deviation from the Java reference: Commons Codec matches a rule context that contains no `[` (e.g. `(а|е|о|и|у)`) as a LITERAL string (an optimisation in `Rule.pattern`), so those alternation contexts never fire. I treat every context as the regex it is written as. Effect measured against the real jar on 131 names (fixture spellings + extras, Latin/Cyrillic/Arabic/Greek/Hebrew): 127 identical; the 4 differences are all Cyrillic names (Ольга, Сергей, Евгений, Ольга Петрова) where mine adds the alternatives the rule author wrote. With the literal quirk reproduced the port was 131/131 identical but pair count 132 instead of 134 (BM only). Switchable in one function if the lead prefers the reference behaviour (I kept a scratch copy of that variant outside the repo).
- Double Metaphone for Cyrillic/Arabic is computed on the anyascii form (lossy, language-agnostic; documented). It lifts the count 134 -> 143.
