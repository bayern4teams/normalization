## Ambiguity in the spec (decided; flag if wrong, the worker brief must carry these)
- `report.outcomes`: list of outcome strings in input order, or a list of `(case, outcome)` pairs. (A dict keyed by case is impossible: `GoldCase` holds a dict.)
- `krippendorff_alpha(data)`: `data` is coders x units (list of per-coder lists), `None` = missing; units with <2 judgements drop out; unknown `level` raises ValueError. Only nominal is required (interval 0.849 not tested).
- `cohen_kappa(a, b)`: two equal-length label sequences; unequal -> ValueError.
- Generated PHONE truth is E.164 (`expected_value`), context keys are `NormalizationContext` fields (`country` / `default_region` for region, `locale`). AMBIGUOUS cases have `expected_value=None`; DATE AMBIGUOUS candidates are the two ISO readings; other AMBIGUOUS families may leave `candidates` empty.
- Classification mirrors `tests/defects/scorer.py`: any clean status (NORMALIZED/UNCHANGED/REPAIRED/PARSED) with the right value is correct; AMBIGUOUS (with or without a value) is the abstention; a clean answer to an AMBIGUOUS truth is wrong-confident even if the value is a listed candidate. Other mismatches (e.g. INVALID for a clean truth) fall outside the four classes and are not asserted.
- `pairs` contains only answers that carry a stated confidence; None-confidence handling is not asserted.
- CSV: `semantic_type` column or kwarg, else error; CSV context is `{}`; CLI scoring of CSV is not specified or tested.
- The published numbers are pure arithmetic and re-derived in the comments; the Artstein & Poesio table cells were reconstructed from memory of the paper (no network check), so the cite is "Table 2 worked example" not a page number. The Krippendorff 2011 layout and 0.743 were recomputed independently to 0.7434.
