# U1 lane C report (Jobs, Review, Quality)

## What changed (all committed and pushed on feat/round2-fixes)
- `ui/src/pages/ReviewPage.tsx`: **named export `ReviewPage`**. One value at a time (raw value, occurrences, all readings, "n of N", context badges). Keys 1-9 pick the n-th reading (= accept and send), `o` text field (Enter sends the typed text, Escape cancels), `k` keep ambiguous (nothing stored, stays pending, "Review the open values again" on the done panel), `u` undo. Each has a Mantine button with a `Kbd` hint and `aria-keyshortcuts`. Nothing pre-selected. List fetched once (`staleTime: Infinity`, no refetch on focus), re-sorted client-side by occurrences desc (stable). A decision is held `UNDO_WINDOW_MS` (5000, `ponytail:` comment in `lib/reviewQueue.ts`) before its POST; leaving the page or `pagehide` flushes held decisions with `keepalive`. The API's 422 text is shown with a "Go back to it" button. POST body `{decided_value, decided_by:"human:reviewer", rationale}`; the rationale never contains the raw value.
- `ui/src/lib/reviewKeys.ts` (pure key to action; ignores modifiers incl. Shift, `repeat`, IME composition, and input/textarea/select/contenteditable targets), `reviewQueue.ts` (pure reducer), `reviewReadings.ts` (defensive extractor of `detail.structured.candidates`), `reviewJobs.ts` (POLL_MS, stateLabel).
- `ui/src/api/review.ts`: `getReviewEntries`, `postVerdict`, `listCloneJobs`, `getJob`, `getJobQuality`, `getJobErrorsPage` (reads `X-Total-Count`), `apiMessage`. Same-origin base (`VITE_API_BASE_URL` only as opt-in). Reuses `ApiError`, `startCloneJob`, `verifyCloneJobDatabase` from client.ts.
- `ui/src/pages/JobsPage.tsx` (**named export `JobsPage`**; filter in `?state=`, buttons built from the states present in the data, so no state list is typed), `JobDetailPage.tsx` (**`JobDetailPage`**; progress, error, 50-per-page errors in `?page=`, polls while RUNNING, "Verify database" / "Start clone" in their states), `QualityPage.tsx` (replaces the old file; **`QualityPage`**; job in `?job=`, polls while RUNNING, per-column outcome bars).
